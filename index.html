⚙️ Pasos para activar Google Sheets:

1. Abre Google Sheets y crea una hoja nueva
2. Agrega columnas: Timestamp, Nombre, Edad, Teléfono, Programa, Modalidad, Horario, Fuente
3. Ve a Extensiones → Apps Script
4. Pega el código del Apps Script (te lo doy si lo pides)
5. Despliega como aplicación web y copia la URL
6. Reemplaza TU_SCRIPT_ID_AQUI en el código del chatbot
